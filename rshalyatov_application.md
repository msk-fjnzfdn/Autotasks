### НАЗВАНИЕ ПРОЕКТА

“Autotasks”

### ПРОБЛЕМНОЕ ПОЛЕ

Из-за обилия рутины: фильтрация статей, преобразование данных их одного формата в другой, фильтрация файлов с логами, поиск среди них же ключевой информации, и тд - которую хочется автоматизировать её, но не хочется каждый раз писать полноценный скрипт или не достаёт для этого знаний, при этом хочется видеть, что именно выполняется, и контролировать безопасность. Этот проект решает это проблемное поле благодаря лёгким для понимания блокам на сайте с реализованным в них функционалом для автоматизации.

### ЗАКАЗЧИК / ПОТЕНЦИАЛЬНАЯ АУДИТОРИЯ

1. Люди имеющие много задач, но не знающие язык программирования в достаточной мере.
   * Обычно это помощники администраторов с однотипным функциями.
2. Люди, заинтересованные в автоматизации, но не умеющие это делать.
   * Начинающие DevOps-инженеры, только входящие в сферу.

### АППАРАТНЫЕ / ПРОГРАММНЫЕ ТРЕБОВАНИЯ

* Программные требования:
* Подключение к интернету
* Последняя рабочая версия браузера (Yandex browser, Chrome, Firefox и тд.)

### ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ

1. Конструктор цепочек действий из готовых блоков
2. Библиотека готовых блоков с описанием и примерами
3. Изменение параметров внутри блоков для найстройки их работы
4. Тестовый запуск одного шага или всей цепочки с выводом промежуточных результатов.
5. История запусков и логи выполнения
6. Планировщик задач — запуск по расписанию
7. Сохранение/загрузка конфигурации
8. Ролевая модель и контроль доступа


### ПОХОЖИЕ / АНАЛОГИЧНЫЕ ПРОДУКТЫ

Анализ 3 программных продуктов, которые максимально приближены к заданному функционалу, показал, что:

* Продукт1 - "n8n": отсутствует возможность загружать свои цепи, требует глубоких знаний языковв программирования для настройки

* Продукт2 - "SimpleOne": требует знаний JS, требует отбельной заявки для подключения демо продукта

* Продукт3 - "ELMA365": управленение документами/работа с коммуникацией между клиентами

### ИНСТРУМЕНТЫ РАЗРАБОТКИ, ИНФОРМАЦИЯ О БД

HTML / CSS / JS / Fastapi – для разработки веб-версии

PostgreSQL - база данных
